# The Hidden Mind

Production repo for the YouTube channel **The Hidden Mind**: animated psychology for overthinkers.
See `CLAUDE.md` for the full pipeline (voiceover → animated episode → thumbnail → Short → private YouTube upload).

- Episode 1: *The Truth About Overthinking*, `studio/projects/overthinking-full`, `episodes/ep01-the-truth-about-overthinking`
- Quick start: `bash tools/setup.sh`, then `node studio/render.mjs --project studio/projects/overthinking-full --sheet --scale 0.4`
